# Jago Workscape 0.5.2

An optional tabbed home for Jago studios, with working pairs, detachable tabs and editable workspace saves.

This repository contains the application source, examples, licence notices and illustrated guide. See **DEVELOPING.md** to build it. Ready-to-use Windows downloads belong under GitHub Releases.

## Get started

Read **Documentation/Jago-Workscape-Guide.pdf** for an illustrated introduction. The app’s **?** menu provides help and shortcuts. Open several studios in tabs, choose a pair to compare, or detach a studio into its own window.

## About & rights

Open source. Free forever. Personal, professional and commercial use are welcome. Imported assets and third-party components retain their own licences; see LICENSE.txt and Notices where included.

The complete suite is distributed by the separate Jago-Suite repository. This repository contains Workscape itself. **Documentation/Jago-Suite-Full-Guide.pdf** explains the connected studio workflows. Workscape is a Windows companion application; it has no browser demo.
