# Jago Workscape 0.5.5

Your studios, together.

An optional home for Jago tools. Open studio tabs, compare two views and keep a connected creative session together. Each studio can also work independently.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Workscape/releases/latest)

## Get started

Download **Jago-Workscape-v0.5.5.zip**, right-click it and choose **Extract All**. Open **Jago-Workscape.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Workscape-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Open installed or portable studios from Home; choose an explicit app location in Manage studios.
- Work with tabs, side-by-side pairs and detached windows.
- Save editable workspace snapshots and return to recovered sessions.
- Use Companion as a full tab, an adjustable narrow panel or a floating note.
- Home shortcuts provide quick access to Capture and Board.
- Pulse joins the editable studio tabs, including embedded music, artwork and fonts in workspace saves.
- Companion reuse, sidebar and floating integration have been refined.
- Close all tabs offers a save route while detached windows remain independent.
- Studio discovery, snapshot access and native bridge handling have been strengthened.
