# Jago Workscape

A place to bring your studios together.

Open creative tools in tabs or side by side. Move work between studios and save a workspace so you can get back to the documents you were using.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-Workscape.exe**.

Open Workscape and choose a studio from Home. Add a second tab when you need another tool, or open a working pair.

[Find Jago Suite and downloads](https://jagosuite.co.uk/)
